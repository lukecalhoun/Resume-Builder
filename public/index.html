Library Attribution

This application was built using the following libraries and tools:

  • Bootstrap — used for frontend styling and layout.
  • Express — used for backend routing and RESTful services.
  • SQLite / sqlite3 — used for local database storage.
  • dotenv — used for environment variable support during development.
  • nodemon — used during development to restart the server automatically.
  • Google Gemini API — used to suggest improvements to resume bullet points.
