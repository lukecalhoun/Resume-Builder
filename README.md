# Resume Builder

Resume Builder is a local single-page web application that helps users create and preview a resume. Users can enter profile information, jobs, job responsibilities, skills, certifications, and awards. The app stores this information in SQLite and allows users to select which items should appear on the resume preview.

## Technologies Used

- HTML
- JavaScript
- Bootstrap
- Node.js
- Express
- SQLite
- Google Gemini API
